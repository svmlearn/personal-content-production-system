# 2026-06-04 海外服务器购买选型 Handoff

## 当前目标

为个人作品集 / 简历展示网站选择一台便宜服务器，用于后续上线当前仓库里的个人网站与几个前端项目。

用户明确预算倾向：

- 优先找活动价，目标大约 100 多元 / 年。
- 640 元 / 年左右的香港 2 核 2G 方案太贵，暂不考虑。
- 不想为个人展示站点承担过高固定成本。

## 已确认约束

1. 域名是在阿里云购买的。
2. 用户希望尽量不做 ICP 备案。
3. 因此服务器优先选择中国大陆以外地域，例如中国香港、新加坡、日本、美国等。
4. 域名注册商在阿里云，不影响解析到海外 / 中国香港服务器。
5. 国内用户通常可以直接访问解析到海外 / 中国香港 IP 的域名，不需要翻墙；但速度、稳定性和不同运营商线路质量不一定稳定。
6. 如果未来使用中国大陆 CDN、对象存储静态网站绑定大陆域名、或大陆服务器公开建站，通常会重新触发备案要求。

## 当前判断

中国香港 + 2 核 2G 在阿里云轻量正式购买页上的价格偏贵。下一轮应重新围绕「活动价」找方案，而不是从常规购买页硬选。

更合理的下一步是先查可用活动：

1. 阿里云轻量海外 / 中国香港活动机，尤其 1 核 1G、2 核 1G、2 核 2G 的首年价。
2. 腾讯云轻量中国香港 / 新加坡活动机。
3. 阿里云国际站、腾讯云国际站是否有更低首年价。
4. 其他可接受平台：Vercel / Cloudflare Pages 静态托管 + 后端另放；或便宜 VPS，例如 RackNerd、Vultr、Hetzner、Lightsail 等，但要单独评估国内访问质量和付款便利性。

## 选型建议方向

如果只是个人作品集首页和几个前端展示项目：

- 静态作品集可以优先考虑 Vercel / Cloudflare Pages / Netlify 这类前端托管。
- 小红书 / 抖音平台如果需要真实后端、PostgreSQL、OSS、worker，则需要单独部署后端服务，不能只靠静态托管。
- 如果短期只是给别人看简历展示，最低成本路径可能是：
  - 前端先上 Vercel / Cloudflare Pages；
  - 后端复杂项目先不上生产，或只保留前端演示；
  - 真正需要完整后端时再买 VPS。

如果坚持一台服务器承载所有内容：

- 优先找中国香港 / 新加坡轻量活动机。
- 1 核 1G 可以跑静态站和简单 Node 服务，但跑多个 Next app + PostgreSQL 会紧。
- 2 核 2G 更稳，但活动价未必能压到 100 多元 / 年。
- 如果要本机同时跑 PostgreSQL、多个 Node 进程、反向代理和构建产物，2 核 2G 是更合理的下限。

## 下一轮继续时的建议任务

下一轮不要直接进购买页。先做价格筛选：

1. 查阿里云、腾讯云官方活动页中「中国香港 / 海外 / 免备案 / 轻量应用服务器」的当前活动价。
2. 只保留年付 100-300 元附近的方案。
3. 对每个候选写清楚：
   - 地域
   - 规格
   - 带宽 / 流量限制
   - 首年价
   - 续费价
   - 是否需要备案
   - 是否适合跑当前个人网站
4. 再让用户决定是否进入对应购买页。
